# Fresh boot and startup readiness — 2026-10-27

The owner's required fresh-phone sequence is **boot animation → keyguard → explicit unlock → launcher**. This applies to all eight releases, including private browsing and a reduced-motion preference. A previously configured lock type None is still respected; fresh phones use their default keyguard. Reloading an already completed boot in the same tab retains the existing once-per-version/session behavior. Blocked storage cannot suppress a boot, and the session marker is written only after completion.

History: `65d64c98` (2026-10-08) introduced the cold-boot reduced-motion/storage early returns. `75751f6d` (2026-10-19) changed Marshmallow to boot home without a secure lock; Nougat adopted this behavior in `90fc0a0f`. The boot movies were still present. Marshmallow/Nougat exited their looping part after a fixed six seconds, without waiting for drawer icons or decoded movie sheets; the older versions waited only for page load/fonts, with a twelve-second escape.

`boot-ready.js` now gates the movie's exit on decoded launcher icons plus current wallpaper, keyguard/status/navigation pictures and fonts. It uses the release's own app registry/markup and styles; it does not import other releases' art or fetch entire application libraries. Images are fetched with eight workers. Failed image requests/timeouts are recorded as degraded readiness, rather than hanging forever; normal checks require zero failures. Boot sheets start downloading while the HTML is parsed and are decoded before playback. An explicit skip waits for startup readiness too. Native part order/loop boundaries remain in the release's player.

Validation: 275/275 module tests. `boot-startup.mjs` uses a fresh Chrome incognito profile with disabled cache on all eight versions, normal motion and reduced motion plus simulated blocked boot storage. It verifies the visible boot/keyguard/unlock sequence and fully loaded drawer images. A deliberately withheld Nougat calculator icon keeps boot visible beyond seven seconds and cannot be bypassed by a skip. The same two Nougat cases passed in Edge InPrivate. Existing boot, settings, language persistence and old-save browser flows passed for all seven versions they cover. The shared MM/NG harnesses now explicitly swipe the default keyguard instead of assuming a fresh boot goes home.
